##This project is a quick commerce application developed in nodejs, mongodb, postgres

This app will have 4 main component
1. User facing webapp, from where customer would be interacting
2. Warehouse webapp, where all the order packging part would be maanged
3. Admin back office kind of dashboard for analytics and tracking
4. Backend System containing webservices for 
	   - Authentication Service
	   - Product Catalog Service
	   - Order Management Service
	   - Payment Processing Service
	   - Warehouse Management Service
	   - Analytics & Reporting Service
	   - Customer Support Service
	   - Notification Service

 **Database Layer**:
   - MongoDB for product catalog, user profiles
   - PostgreSQL for transactional data, orders, payments
   - Redis for caching and session management

 **DevOps Components**:
   - CI/CD pipeline
   - Containerization with Docker
   - Container orchestration with Kubernetes
   - API Gateway for routing
