Develop a NodeJS Customer Support Service for a quick commerce delivery application with these requirements:

1. Use Express.js with TypeScript and RESTful API design
2. Implement MongoDB for storing support-related data:
   - Support tickets (customer info, issue description, status, priority)
   - Chat conversations
   - Frequently asked questions
   - Canned responses
   - Customer feedback and ratings
3. Create endpoints for:
   - Ticket creation, assignment, and management
   - Live chat functionality (WebSocket integration)
   - FAQ management and retrieval
   - Customer feedback collection and analysis
   - Support agent performance metrics
   - Order issue resolution workflows
   - Automated response suggestions
4. Implement integration with order management for context-aware support
5. Add sentiment analysis for customer messages
6. Create notification system for new and escalated tickets
7. Implement ticket prioritization algorithms
8. Add comprehensive validation and error handling
9. Create unit and integration tests using Jest
10. Include Swagger/OpenAPI documentation

The service should follow microservice best practices, be containerized with Docker, include proper logging for support interactions, and implement WebSocket connections for real-time chat capabilities.
