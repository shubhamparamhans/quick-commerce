Develop a React-based customer-facing web application for a quick commerce delivery platform with the following requirements:

1. Use React 18+ with TypeScript and modern hooks pattern
2. Implement state management using Redux Toolkit or React Query
3. Use Tailwind CSS for responsive styling
4. Create the following key pages and components:
   - Homepage with featured products and categories
   - Product listing page with filters (price, category, rating)
   - Product detail page with variants selection and add to cart
   - Shopping cart with real-time updates
   - Checkout process (address, payment method, order summary)
   - User authentication (register, login, password reset)
   - User profile (personal details, addresses, payment methods)
   - Order history and tracking
   - Wish list functionality
   - Search with autocomplete suggestions
5. Implement responsive design for mobile, tablet, and desktop
6. Add loading states and skeleton loaders for API calls
7. Implement error handling and user-friendly error messages
8. Create form validation using Formik or React Hook Form
9. Add animations and transitions using Framer Motion
10. Implement performance optimizations (lazy loading, code splitting)
11. Add unit and integration tests using Jest and React Testing Library
12. Include accessibility features (ARIA attributes, keyboard navigation)

Ensure the application has a modern, intuitive UI focused on quick product discovery and easy checkout. Include a location-based delivery time estimate feature and real-time order tracking capabilities.
