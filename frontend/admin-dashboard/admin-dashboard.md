1. Use React 18+ with TypeScript and functional components
2. Implement state management using Redux Toolkit
3. Use a component library like Chakra UI or MUI for styling
4. Create data visualization with Recharts or Chart.js
5. Develop the following key sections and features:
   - Executive dashboard with KPIs and business metrics
   - Sales analytics with filtering and comparison options
   - Customer management and segmentation
   - Order management with advanced filtering and bulk actions
   - Product catalog management with bulk editing capabilities
   - Inventory overview across warehouses
   - Promotion and discount creation and management
   - Delivery performance monitoring
   - User management for staff accounts and permissions
   - System configuration and settings
   - Financial reporting and reconciliation
6. Implement advanced data tables with sorting, filtering, and export
7. Create customizable dashboard widgets with drag-and-drop layout
8. Add scheduled reports generation and distribution
9. Implement role-based access control with granular permissions
10. Create audit logs for administrative actions
11. Add form validation and error handling
12. Implement responsive design for various screen sizes
13. Write unit and integration tests using Jest and React Testing Library
