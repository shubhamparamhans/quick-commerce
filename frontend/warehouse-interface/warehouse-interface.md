Create a React-based Warehouse Management Interface for a quick commerce delivery platform with the following specifications:

1. Use React 18+ with TypeScript and functional components
2. Implement state management using Redux Toolkit or React Query
3. Use Material UI or Ant Design for component styling
4. Create the following key features and screens:
   - Dashboard with key metrics (pending orders, inventory levels, staff performance)
   - Order processing queue with priority indicators
   - Interactive picking lists with barcode/QR scanning capability
   - Packing station interface with order details and instructions
   - Inventory management screens (stock levels, relocations)
   - Staff assignment and performance tracking
   - Quality control checklists and verification
   - Returns processing workflow
   - Delivery handoff interface with signature capture
5. Implement real-time updates using WebSockets
6. Add barcode/QR code scanning functionality
   - Support for camera on mobile devices
   - Support for USB barcode scanners on desktop
7. Create intuitive drag-and-drop interfaces where appropriate
8. Implement role-based access control for different warehouse staff roles
9. Add comprehensive form validation and error handling
10. Create color-coded visual indicators for priorities and statuses
11. Implement responsive design for both desktop and mobile tablet use
12. Write unit and integration tests using Jest and React Testing Library

The interface should prioritize efficiency and speed for warehouse operations, with clear visual cues and minimal clicks for common actions. Focus on creating workflows that minimize errors and maximize throughput.
